Seating Generator

Each class has its own names, attendance, restrictions, groups and a seating chart for every classroom. The class name is also the chart title. Classrooms (seats and table colours) are shared by all classes. Everything is stored in this browser only, so export a backup to keep it safe or to move it to another computer.

Names

One name per line, or paste a list from a spreadsheet (numbering and number/email columns are removed). Changes apply when you click outside the box. The current seating is kept: new names take a free seat, removed names free theirs.

Attendance: click a name to mark them absent.

Restrictions

Add rules without showing them in Student View.

Classroom layout:

Empty cells work as gaps/aisles. Resizing keeps existing seats (rows/cols change at the bottom/right).

Display & privacy

Student View hides everything except the seating chart. Optional PIN prevents switching back (one PIN for all classes).

Groups

Split the students who are present into groups, e.g. for a project. The groups can be shown and generated in Student View too.
